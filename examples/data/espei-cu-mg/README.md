# Cu–Mg datasets from ESPEI-datasets

These files are copied unchanged from
[PhasesResearchLab/ESPEI-datasets](https://github.com/PhasesResearchLab/ESPEI-datasets),
directory `datasets/2-binary/Cu-Mg`, at commit
`e3b536426e20d8d3712e9cd7d7fcf7ac4e67f07d`.

They are licensed under
[Creative Commons Attribution 4.0 (CC-BY-4.0)](https://creativecommons.org/licenses/by/4.0/)
by the contributors to that repository. Each file names the publication its
data come from in its `"reference"` key. The BibTeX entries for those keys are
in that repository's `references.bib`.

`examples/cumg_espei_fit.py` fits Cu–Mg parameters to these data, and
`tests/test_fit.py` reads them.
